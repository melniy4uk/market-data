# Market Data

**Market Data** — Python-библиотека для получения, хранения и предоставления исторических рыночных данных из различных источников.

Библиотека предоставляет единый интерфейс для работы с данными независимо от биржи или торговой платформы.

## Основные задачи

- Получение рыночных данных из Bybit и MetaTrader 5.
- Поддержка тиков и свечей.
- Локальное кэширование исторических данных.
- Автоматическая дозагрузка отсутствующих периодов.
- Единые модели данных для разных источников.
- Расширяемая архитектура для подключения новых провайдеров.

## Принципы

- **Простота** — понятный публичный API.
- **Модульность** — независимые компоненты получения и хранения данных.
- **Расширяемость** — возможность добавлять новые источники и хранилища.
- **Повторное использование** — минимизация повторных запросов к источникам.

## Статус

Проект находится на ранней стадии разработки.
